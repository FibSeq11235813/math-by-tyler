# Math by Tyler Website

A static, responsive one-page site for https://mathbytyler.com/

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/favicon.svg`
- `robots.txt`
- `sitemap.xml`

## Launch notes
1. Upload the contents of this folder to your current web host/root.
2. The consultation form currently uses `mailto:tyler@mathbytyler.com`.
3. Replace the portrait placeholder in the About section with a real photo when ready.
4. If you use Formspree or another form service, replace the current JavaScript mailto handler with that endpoint.

The site uses Google Fonts (DM Sans + Fraunces), so internet access is required for those fonts to load.
